# CAT LOUNGE nonnon 公開用PWAファイル

## 内容
- `index.html` : 現在の確認書・電子署名ページ
- `manifest.webmanifest` : ホーム画面追加用の設定
- `sw.js` : 基本キャッシュ用Service Worker
- `icons/` : ホーム画面アイコン

## 公開方法（GitHub Pages）
1. GitHubで新しいPublicリポジトリを作成します。
2. このフォルダ内のファイル・フォルダを、リポジトリの一番上（root）へアップロードします。
3. Repository Settings → Pages → Deploy from a branch を選び、`main` / `/ (root)` を指定して保存します。
4. 公開された `https://....github.io/.../` のURLを各店舗のiPadで開きます。
5. Safariの共有ボタン →「ホーム画面に追加」でアイコンを追加します。

## 大切な注意
- 署名データは引き続き、そのブラウザ／iPad内のIndexedDBに保存されます。店舗間で同期されません。
- 同じ店舗でも、iPadを交換・初期化した場合は記録が引き継がれません。定期的に管理画面からJSONバックアップを保存してください。
- この構成は公開URLから誰でもお客様受付画面を開けます。
- 現在のスタッフ用パスワード認証はHTML/ブラウザ内の簡易ロックです。サーバー側の認証ではないため、機密情報を守る強固なセキュリティ機能とはみなせません。公開前に初期パスワードを変更し、署名記録を保存するiPadを店舗内で管理してください。
- 外部CDN（React、Tailwind、Babel、Google Fonts）を利用するため、初回起動や更新時にはインターネット接続が必要です。オフライン動作は完全保証ではありません。
- このファイル一式は公開用の土台です。公開URLの発行やGitHubへのアップロードは、GitHubアカウント上での操作が必要です。
